
# SlideSpace 🧠🎓

**SlideSpace** is a web-based AI-powered tool that automatically generates presentation slides from scientific research papers (especially AI/ML/CV papers). The goal is to simplify the presentation process for students, researchers, and professionals.

> 🚀 Built as a Graduation Project – Faculty of Computers and Artificial Intelligence, Helwan University  
> 🎯 Final Grade: 99/100 (A+)

---

## 🎯 Project Objective

To automate the generation of clear, editable, and presentable slides from research papers using AI — reducing manual work and saving time for presenters.

---

## 🛠️ Technologies Used

### Frontend:
- HTML5 / CSS3 / JavaScript 
- TailwindCSS
- React
- Reveal.js (Custom integration)
- lightGallery (Image viewer)

### Backend:
- Pure PHP (MVC architecture)
- MySQL
- RESTful API (custom built)

### Other Tools:
- AI model response integration (text + image)
- PDF parser
- PPTX & PDF export builder
- Secure session-based authentication

---

## 🔑 Key Features

- Upload AI/ML/CV research paper (PDF)
- Auto-generate slide titles, bullet points, and suggested images
- Web-based slide editor with live preview
- Export slides as `.pdf` or `.pptx`
- User registration & login
- Rate and give feedback on generated slides
- Admin panel for managing users and content
- Role-based access control (user/admin)
